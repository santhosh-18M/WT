# Road Damage Detection System

Road Damage Detection System is a full-stack web application for road condition reporting. Users can sign up, log in, upload road images, store predicted damage reports, view reports on a dashboard, and manage report records.

The project is designed for learning and extension:
- It works immediately with a fallback prediction flow.
- It can be upgraded to use a real TensorFlow.js model.

## Features

- User authentication with JWT (`signup`, `login`, protected routes).
- Image upload with validation (JPEG/PNG, max 5 MB).
- Damage report creation with confidence score and location details.
- Personal dashboard to view, edit, and delete reports.
- Map view with heatmap overlay using Leaflet + Leaflet Heat plugin.
- Automatic GPS capture during upload with browser geolocation.
- Admin dashboard with all reports view, area/damage filters, and analytics charts.
- Ready-to-use Postman collection for API testing.
- ML inference hook with fallback when no trained model exists.

## Architecture Overview

- `client/` provides the UI and routing.
- `server/` exposes REST APIs and handles business logic.
- MongoDB stores users and damage reports.
- Uploaded files are stored on disk under `server/uploads/`.
- Prediction is generated by `server/utils/mlInference.js`:
  - Uses a TensorFlow model when available.
  - Falls back to demo logic when model is missing.

## API Reference

Base URL: `http://localhost:5000`

### Health
- `GET /api/health`

### Auth
- `POST /api/auth/signup`
  - Body: `{ "name", "email", "password" }`
- `POST /api/auth/login`
  - Body: `{ "email", "password" }`

### Reports (requires `Authorization: Bearer <token>`)
- `GET /api/reports` - get current user's reports
- `POST /api/reports` - create report from multipart form data
  - Form fields:
    - `image` (required, jpeg/png)
    - `location` (optional)
    - `damageType` (optional override)
    - `confidence` (optional override)
    - `latitude` (optional)
    - `longitude` (optional)
- `PUT /api/reports/:id` - update `damageType` and/or `location`
- `DELETE /api/reports/:id` - delete report

### Admin Reports (requires admin token)
- `GET /api/reports/admin` - view all reports with optional filters
  - Query params:
    - `area` (matches report location)
    - `damageType` (exact damage type match)
- `GET /api/reports/admin/analytics` - aggregated dashboard analytics

## ML Inference Behavior

The server tries to load a TensorFlow.js model from `server/ml-model/model.json`.

If model loading fails or model file is missing, it uses fallback logic based on filename and returns one of:
- `Surface Wear`
- `Road Break`
- `Edge Damage`

This ensures the app remains usable even before integrating a trained model.

## Troubleshooting

- MongoDB connection error (`ECONNREFUSED 127.0.0.1:27017`):
  - Start MongoDB service locally, or update `MONGO_URI` to your hosted DB.
- `concurrently is not recognized` when running root scripts:
  - Run `npm install` in project root to install root dev dependencies.
